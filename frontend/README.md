# Frontend de Social Content Studio

La documentación de arquitectura, configuración, instalación y uso se mantiene en el [README principal](../README.md).

Inicio rápido desde este directorio:

```bash
npm ci
npm run dev
```

La aplicación estará disponible en [http://localhost:3000](http://localhost:3000). Antes de iniciarla, configura `frontend/.env.local` y levanta los servicios definidos en `../docker-compose.yml` siguiendo las instrucciones del README principal.
